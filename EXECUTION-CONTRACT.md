\# Execution Contract



\## Responsibility



Representar um contexto de execução.



\## Required



\- id



\- title



\## Rules



1\. Toda Execution possui identificador único.



2\. Toda Execution representa um único contexto.



3\. Execution agrega Execution Events.



4\. Execution nunca conhece documentos.



5\. Execution nunca calcula conformidade.
