\# Event Contract



\## Required



\- id



\- type



\- title



\- execution



\---



\## Optional



\- occurredAt



\- actor



\- location



\---



\## Rules



1\. Todo Event possui identificador único.



2\. Todo Event pertence a uma Execution.



3\. Todo Event pode produzir múltiplas Evidences.



4\. Um Event representa apenas uma ocorrência observável.
