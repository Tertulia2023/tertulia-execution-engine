\# Execution Engine Ontology



\## Objects



\### Execution



Conjunto organizado de Events.



\---



\### Event



Ocorrência observável durante uma Execution.



\---



\### Evidence



Registro verificável produzido por um Event.



\---



\### Obligation



Condição que deve ser comprovada.



\---



\## Relations



Execution HAS Event



Event PRODUCES Evidence



Evidence SATISFIES Obligation



\---



\## Rules



1\. Todo Event pertence a uma Execution.



2\. Toda Evidence pertence a um Event.



3\. Toda Obligation pode ser satisfeita por uma ou mais Evidences.



4\. Nenhuma Evidence existe sem Event.
